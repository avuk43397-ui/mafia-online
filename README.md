# Dub Studio

Браузерная мини-студия озвучки, сделанная под формат dub-паков: ZIP/папка → импорт роликов и текста → сцены → запись дублей → экспорт MP4.

## Что уже есть

- Импорт ZIP через JSZip.
- Импорт папки через `webkitdirectory`.
- Автоматическое обнаружение видео и файлов сценария.
- Поддержка TXT / SRT / VTT / JSON.
- Связка видео и текста по имени файла и порядку.
- 2 диктора: A и B.
- Переключатель «Слышать оригинал / Не слышать оригинал».
- Проверка микрофона.
- Несколько дублей на сцену.
- Прослушивание, удаление и выбор основного дубля.
- Прогресс проекта.
- Сборка MP4 прямо в браузере через FFmpeg.wasm.

## Важно

Экспорт MP4 происходит прямо в браузере. Для очень больших исходников FFmpeg.wasm может потребовать много оперативной памяти. Для клипов и коротких сцен это подходит намного лучше.

## Запуск локально

Не открывай `index.html` двойным кликом: браузер может заблокировать микрофон и некоторые WASM-ресурсы.

В папке проекта запусти:

```bash
python -m http.server 8080
```

и открой `http://localhost:8080`.

## Бесплатный хостинг

Это статический сайт. Подойдут Netlify, Cloudflare Pages, GitHub Pages или любой хостинг, который отдает HTML/JS/CSS.

Файл `_headers` содержит COOP/COEP-заголовки, полезные для браузерного WASM-плеера. Если конкретный хостинг не поддерживает `_headers`, сайт все равно стоит сначала проверить; для тяжелого FFmpeg-экспорта лучше хостинг с поддержкой этих заголовков.

## Ожидаемый формат dub-пака

Простейший вариант:

```text
pack/
  01_intro.mp4
  01_intro.txt
  02_scene.mp4
  02_scene.txt
```

TXT может содержать один или несколько текстовых блоков по строкам. Для таймкодов можно использовать SRT/VTT. JSON тоже поддерживается в виде массива объектов с `start`, `end`, `text`.

## Ограничения MVP

- На экспорт берется первый (основной) дубль выбранного диктора для каждой сцены.
- Экспорт заменяет оригинальную аудиодорожку озвучкой.
- Для реального удаленного дубляжа двух людей по интернету понадобится отдельный room-сервер/WebRTC; текущая версия рассчитана на локальную работу в одной вкладке/на одном проекте.
